08 / CONTROLS PAIN POINTS + EXCEPTION HANDLING

Most rework starts with a bad match.

Validate before posting, then route exceptions to the processor first.
01

Invalid WBS

Projects move to new WBS elements; old and new can share similar names.

02

Company Code vs WBS mismatch

Ownership context can disagree before the posting is submitted.

03

SAP posting errors

WBS locked or closed, account not allowed, or different company code.

04

F-63 usability constraint

F-63 provides only approximately 18 lines, sometimes not enough for splits.

Exception route: error → processor first Success themes: reduce manual effort and improve compliance / audit trail.
